# QR Code Generator 🧾⚙️

A simple QR Code Generator built using **React.js**. This web app allows users to enter custom text or URLs, generate QR codes, and download them as images.

## 🚀 Features

- ✅ Generate QR codes from any text or URL
- ✅ Choose custom image size
- ✅ Shows a loading countdown before generation
- ✅ Download the generated QR code as a PNG file
- ✅ Responsive and user-friendly design

## 🛠️ Technologies Used

- React.js (with Hooks: `useState`, `useEffect`)
- HTML5 & CSS3
- [QR Code API](https://goqr.me/api/)
- JavaScript Fetch API
